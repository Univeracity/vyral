# Vyral library package

This package is one component of Vyral, a provider-neutral contract and adapter
suite for portable application data, retrieval, and durable execution. Use a
version-compatible set of Vyral packages; provider adapters intentionally add
capabilities without changing the portable contract.

For package-specific APIs, supported providers, configuration, and current
limits, see the [Vyral repository](https://github.com/univeracity/vyral).
The source, issue tracker, security reporting path, and Apache-2.0 license are
available there as well.
